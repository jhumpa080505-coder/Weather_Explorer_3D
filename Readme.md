# Weather Globe Explorer

An interactive weather visualization web application that combines a 3D Earth experience with real-time weather forecasting. Users can search for any city, locate it on a rotating globe, and explore detailed weather information through a modern and responsive interface.

## ✨ Features

* 🌎 Interactive 3D Globe Visualization
* 📍 City Search with Location Highlighting
* 🌡️ Real-Time Current Weather Information
* ⏰ Hourly Weather Forecast
* 📅 7-Day Weather Forecast
* 🌬️ Air Quality Index (AQI) Display
* ☀️ Dynamic Weather-Based Animations

  * Sunny
  * Rainy
  * Cloudy
  * Snowy
  * Stormy
* 🎨 Modern Glassmorphism UI Design
* 📱 Responsive Layout for Different Screen Sizes

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Globe.gl
* Three.js
* WeatherAPI

## 🚀 How It Works

1. Search for a city using the search bar.
2. The globe automatically locates and highlights the searched city.
3. The application navigates to the weather dashboard.
4. View:

   * Current weather conditions
   * Hourly forecasts
   * 7-day forecast
   * Air Quality Index
   * Dynamic weather animations
